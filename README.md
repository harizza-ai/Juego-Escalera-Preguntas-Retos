# Juego-Escalera-Preguntas-Retos
juego de mesa inspirado en Serpientes y Escaleras y Trivial, diseñado para 2 a 4 jugadores. El tablero estará compuesto por 50 casillas numeradas, desde la salida hasta la meta. Los jugadores participarán por turnos, lanzando un dado para determinar cuántas casillas deben avanzar.
